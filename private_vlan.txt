make sure that: 
- VTP mode is on transparent mode
- Only one isolated VLAN
- You can have as many as we want of Community VLANs
-------------------
example: 
primary VLAN 100
Secondary: 
  -Isolated vlan 200
  -community vlans ( 300,400,500)
port types: 
 - promiscuous port always in primary vlan (gateway port). It can talk to any port
 -Isolated port. talk only to promiscuous port
 -Community port. talk to same community ports and promiscuous port.
----------------------------------------------
creating vlans:
vlan 200
private-vlan isolated

vlan 300
private-vlan community
vlan 400
private-vlan community
vlan 500
private-vlan community

vlan 100
private-vlan primary
private-vlan association 200,300,400,500
exit
------------------------
configuring the promiscuous port:
int gig0/11
 switchport mode private-vlan promiscuous
 switchport private-vlan mapping 100 200,300,400,500
---------------------
configuring the isolated and community ports:
int range gig0/12-13
switchport mode private-vlan host
swithcport private-vlan host-association 100 200
